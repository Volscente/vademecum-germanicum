# Check Word Already Exist

**What:** Upon type a new word to be added into the table, check if it already exist and notify the user

**Why:** Prevent duplicated words.

**Success looks like:**

- Upon typing the word, the user is notified if it is already present in the table
- Upon anyway trying to save a word that is already present in the table, the user is prevented to save it
- Upon trying to enrich a word that is already present in the table, the “enrich” button is disabled
